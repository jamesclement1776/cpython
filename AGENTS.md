Purpose

This repository contains a CPython 3.14–based fork instrumented with Firmament2 runtime emitters that print NDJSON lines describing parsing, compilation, and execution. The goals:

Keep the stock interpreter correct and fast when instrumentation is disabled.

When enabled, emit a stable, machine-readable event stream suitable for building a Merkle-style DAG in external tooling.

Runtime gates

Set via environment variables (opt-in, no overhead when off):

FIRMAMENT2_ENABLE=1 — enable all emitters.

FIRMAMENT2_INCLUDE_CODE_META=1 — include heavy code object metadata (arg counts, stack size, bytecode hash/size) in CODE_* events.

Canonical event model

Every line is NDJSON with two top-level keys:

envelope: { event_id, pid, tid, ts_ns }
Monotonic per-process event_id, process/thread IDs, nanosecond timestamp.

payload: event-specific fields (see below).

Source scope (TLS)

Events: SOURCE_BEGIN, SOURCE_END

Location: Python/compile.c, Python/pythonrun.c

Fields (payload): filename, source_id (16 hex chars)

Pushed on entry to compile/execute paths, popped on exit. Tokenizer/AST/code emitters read this to attach filename/source_id.

Tokenizer

Event type: "type": "tokenizer"

Location: Parser/lexer/lexer.c in _PyTokenizer_Get → emit_tokenizer_event_json

Fields: kind (numeric token), value (escaped slice), lineno, col_offset, filename, source_id

AST

Event type: "type": "ast"

Location: generated by Parser/asdl_c.py into Python/Python-ast.c → emit_ast_event_json

Fields: kind (node type), lineno, col_offset, end_lineno, end_col_offset, filename, source_id

Code object lifecycle

Events: CODE_CREATE, CODE_DESTROY (both "type": "c")

Location: Objects/codeobject.c

Fields:
Common: code_addr (pointer string), filename, bc_size, bc_hash (FNV-1a 64 of bytecode)
CREATE-only: name, qualname, firstlineno, flags, stacksize, argcount, posonlyargcount, kwonlyargcount, nlocals, source_filename, source_id
DESTROY: source_filename, source_id again (from TLS or co_extra tag captured at create time)

Note: Metadata emission is gated by FIRMAMENT2_INCLUDE_CODE_META. Provenance is stored in a tiny co_extra slot to survive until destroy.

Frame lifecycle

Events: FRAME_ENTER, FRAME_EXIT

Location: Python/ceval.c → _firm2_emit_frame_event at frame push/pop

Fields: code_addr, frame_addr, name, qualname, filename, firstlineno

Adding new emitters (scalable rules)
- Keep the envelope schema stable; add new payload fields under a new event kind rather than changing existing ones.
- Declare helpers in Include/firmament2.h, but put any non-trivial code in exactly one C TU to avoid duplicate symbols.
- Gate emission under FIRMAMENT2_ENABLE and include an opt-in gate for heavy/optional fields if applicable.
- Thread source provenance through SOURCE_BEGIN/SOURCE_END or an equivalent TLS mechanism so downstream events can correlate.
- Update INSTRUMENTATION.md with: hook location(s), payload fields, gating behavior, and a minimal smoke test that exercises the new kind.

Invariants & constraints

When gates are off, behavior matches upstream CPython. Emission code must be side-effect free and avoid allocations on the hot path when disabled.

No duplicate definition of helpers; Include/firmament2.h must contain declarations + force-inline trivial helpers only. Any out-of-line definitions live in exactly one C TU.

Use small, bounded buffers for JSON formatting; no heap unless unavoidable.

Do not change bytecode semantics or interpreter flags.

Branch map (incremental series)

firm2/01-core — header + runtime helpers (env gate, envelope utilities, TLS accessors)

firm2/02-parse — tokenizer + AST emitters

firm2/03-source-scope — SOURCE_BEGIN/END wired in compile/run paths

firm2/04-code-meta — CODE_CREATE/DESTROY + co_extra provenance tag

firm2/05-frame — FRAME_ENTER/EXIT

firm2/all — rollup branch for convenience and PR demo

Agent rule: implement new features as additive changes stacked on top of the last numbered branch; keep diffs minimal.

Key file pointers & hooks

Header: Include/firmament2.h

Tokenizer: Parser/lexer/lexer.c (_PyTokenizer_Get)

AST glue: Parser/asdl_c.py → generated Python/Python-ast.c

Compilation entry: Python/compile.c (_PyAST_Compile, helpers)

String/file run paths: Python/pythonrun.c (pyrun_file, _PyRun_StringFlagsWithName, run_mod)

Code object lifecycle: Objects/codeobject.c (creation & teardown hooks; co_extra)

Frame execution: Python/ceval.c (frame enter/exit)

Build & smoke test
# Configure & build (example flags; match your system)
./configure --prefix="$(pwd)/build-env" --with-pydebug=no
make -j"$(nproc)"
make install

# Point shim to the built interpreter (if needed)
ln -sf python3.14 build-env/bin/python
./build-env/bin/python -VV

# Gated run: interactive string (no source scope) and file (with scope)
FIRMAMENT2_ENABLE=1 ./build-env/bin/python -I -S - <<'PY'
def f(x): return x+1
print(f(41))
PY

cat >/tmp/t1.py <<'PY'
def f(x): return x+1
print(f(41))
PY
FIRMAMENT2_ENABLE=1 FIRMAMENT2_INCLUDE_CODE_META=1 \
  ./build-env/bin/python -I -S /tmp/t1.py > /tmp/firm2.out

# Sanity checks
grep -E '"SOURCE_(BEGIN|END)"'  /tmp/firm2.out
grep -E '"type":"tokenizer".*"filename":"/tmp/t1.py"' /tmp/firm2.out | head
grep -E '"type":"ast".*"filename":"/tmp/t1.py"'        /tmp/firm2.out | head
grep -E '"CODE_(CREATE|DESTROY)"' /tmp/firm2.out | head
grep -E '"FRAME_(ENTER|EXIT)"'    /tmp/firm2.out | head
